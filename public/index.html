开始使用工作台

  1. 创建浏览器实例

    为实例命名，填写网站地址；需要代理时在高级选项中设置。

  2. 打开并登录网站

    登录状态会保存在该实例中，下次打开继续使用。

  3. 选择实例，执行任务

    可以用内置任务，也可以在任务脚本中编写自己的 JSON 步骤。

  4. 查看实时预览与结果

    首页每隔数秒刷新预览。点击运行中的预览可切换到浏览器；任务产物在运行控制台查看。

MCP 连接入口位于实例卡片的更多菜单中。

导入浏览器实例

    每条配置会创建一个新的独立实例，登录状态从空白开始。已有实例保持原样。
